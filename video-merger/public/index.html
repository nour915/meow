دمج الفيديوهات

ارفع مقاطعك أو أضف روابط مباشرة، رتّبها بالسحب أو الأسهم، واحصل على فيديو واحد عالي الجودة (H.264 + AAC حتى 1080p)

المصادر — ترتيب القائمة هو ترتيب الدمج

اسحب وأفلته هنا
أو انقر لاختيار ملفات فيديو من جهازك — mp4 / mov / webm / mkv / avi / m4v / mpg / 3gp

    أعد الترتيب بالسحب أو بأزرار ▲▼ — أول مقطع يبدأ الفيديو النهائي. الحدود: 10 مقاطع، 200MB لكل مصدر، 600 ثانية مجموع المدد، الناتج حتى 150MB.

    تحميل الفيديو
    توثيق API — للمطورين (بدون تسجيل دخول، CORS مفتوح، الأخطاء بصيغة {"error":"..."})
    MethodEndpointالوظيفة
    POST/api/jobsإنشاء مهمة دمج — يرجع 201 مع jobId وstatusUrl وprocessUrl وexpiresAt (وuploads[] عند وجود ملفات)
    POST/api/upload?job=&seq=&chunk=رفع أجزاء الملفات (ثنائي ≤4MB) — Content-Type: application/octet-stream
    POST/api/jobs/{id}/processتنفيذ الدمج كاملًا → رابط الفيديو النهائي (متزامن، يستغرق ثوانٍ) — جارية = 202
    GET/api/jobs/{id}الحالة + التقدم (0–100) + الرابط عند الاكتمال
    GET/api/jobs/{id}/videoبث الناتج بدعم Range، و?download=1 للتحميل
    DELETE/api/jobs/{id}حذف فوري شامل
    GET/api/configالحدود العامة + version
    GET/api/cronحذف المهام المنتهية (Cron يومي)
